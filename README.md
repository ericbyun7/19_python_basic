# 파이썬 기초 학습

『파이썬 코딩 도장』을 공부하며 작성한 코드와 문제 풀이입니다.

| 폴더 | 내용 |
|---|---|
| [01_학습](01_학습) | 유닛 04~20, 22~25, 27 학습 예제와 연습·심사문제 |
| [02_과제](02_과제) | 단원별 과제 풀이 모음 |

## 실행 방법

1. VS Code에서 이 저장소 폴더 전체를 엽니다.
2. 노트북의 Python 커널을 선택합니다.
3. 코드 셀을 위에서 아래로 실행합니다.
4. `input()` 셀은 화면 맨 위 입력창에 값을 넣고 Enter를 누릅니다.

유닛 17의 무한 반복 예제는 전체 실행 시 멈추지 않도록 주석으로 표시했습니다.
자세한 환경 설정은 [환경안내.md](환경안내.md)를 참고하세요.

유닛 27의 코드 셀은 개별 실행할 수 있습니다. 필요한 예제 파일이 없으면 `27_실습` 폴더에 준비합니다. 이 폴더는 실행 결과물이므로 Git 업로드에서 제외합니다.
